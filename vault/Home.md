# 🧠 Second Brain

Start here. This vault uses **PARA** folders plus a **Claude Memory** folder that claude-mem fills automatically.

| Folder | What goes in it |
| --- | --- |
| [[00 Inbox/README\|00 Inbox]] | Quick captures. Empty it weekly. |
| [[10 Projects/README\|10 Projects]] | Things with a goal and a deadline. |
| [[20 Areas/README\|20 Areas]] | Ongoing responsibilities (health, finances, a codebase you maintain). |
| [[30 Resources/README\|30 Resources]] | Topics and reference material. |
| [[40 Archive/README\|40 Archive]] | Finished or inactive items. |
| Daily | Daily notes (Daily notes core plugin). |
| [[Claude Memory/Claude Memory\|Claude Memory]] | Auto-generated from claude-mem. Read-only — link to it, don't edit it. |

## Linking your coding work

Every claude-mem project gets a note at `Claude Memory/Projects/<project>.md`.
From your own project note, link it: `[[Claude Memory/Projects/my-app]]`.
Concepts Claude picked up become tags like `#concept/auth`, so the tag pane and graph view show what you've worked on.

## Weekly review

- [ ] Empty `00 Inbox`
- [ ] Skim `Claude Memory` for decisions and next steps worth moving into a project note
- [ ] Move finished projects to `40 Archive`
