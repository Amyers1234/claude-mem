# Second Brain vault — instructions for Claude

This directory is an Obsidian vault. When working here:

- Write notes in Markdown with YAML frontmatter; link with `[[wikilinks]]`.
- Put new captures in `00 Inbox/`, project notes in `10 Projects/`, ongoing topics in `20 Areas/`, reference in `30 Resources/`.
- **Never edit `Claude Memory/`** — it is regenerated from claude-mem and edits are overwritten. Link to it instead.
- Use the templates in `Templates/` when creating daily, project or general notes.
- Prefer updating an existing note over creating a near-duplicate; search the vault first.
